# PowerBI-Sales-Analysis-Dashboard
Interactive Power BI Sales Dashboard built to analyze sales, profit, customers, products, segments, and regional performance through dynamic visualizations and interactive filters.
This project is an interactive Sales Analysis Dashboard developed using Microsoft Power BI. The dashboard provides a comprehensive view of business performance by analyzing key metrics such as Sales, Profit, Quantity, Product Performance, Customer Segments, Regions, and Cities.

Interactive filters and visualizations allow users to explore the data from different perspectives and identify important trends and performance patterns.

🛠️ Tools & Technologies
Microsoft Power BI
Power Query
DAX
Excel
📈 Key Features
Sales and Profit KPI analysis
Sales by Region and City
Product and Category performance
Segment-wise analysis
Interactive slicers and filters
Dynamic charts and visualizations
Business performance insights
